# Social Login & Multilingual Setup (i18n)

Hada projet kamel fih **Social Login (Google & Facebook)** m3a **Support dyal Loghat bzaf (English, Français, العربية)**.

## 📁 Struktur d-projet:
- `index.html`: L-page dyal Login fih Interface nqiya w Responsive.
- `app.js`: Fih l-logic dyal i18n (تبديل اللغة) w handlers d-Login.
- `auth-config.js`: Fih l-configuration dyal App ID w Client ID.
- `locales/`: Fichiers JSON l-kull logha (EN, FR, AR).

## 🚀 Kayfiyyat l-ist3mal:
1. Fta7 `index.html` f l-browser dyalek bch t-testi l-interface w تبديل اللغة (RTL/LTR).
2. Dkhol l `auth-config.js` w zid l-API Keys dyalek d **Google Cloud Console** w **Facebook Developers**.
3. Bch t-ربط m3a Firebase aw Supabase, st3mel l-code l-moujoud f `app.js`.
