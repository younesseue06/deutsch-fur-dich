Netlify manual deploy:
1. Extract this ZIP.
2. Make sure index.html is directly inside the extracted folder, alongside assets/, _redirects and _headers.
3. In Netlify > Deploys, drag the extracted folder (not the ZIP and not its parent folder) into the manual deploy area.
This package is for static pages. Netlify Functions and protected server-side downloads require deploying the full project via Git/Netlify CLI.
