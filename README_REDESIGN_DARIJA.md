# Deutsch Lernen — النسخة المجمعة بتصميم محدث

## شنو كاين فهاد الملف؟
- الموقع الرئيسي Deutsch Lernen بكل الدروس والتمارين والاختبارات وملفات PDF والإعدادات.
- تصميم محدث فـ `public/assets/redesign.css` باش الواجهة تولي أكثر وضوحاً وجاذبية، مع مراعاة الهاتف والكمبيوتر.
- مشروع تسجيل الدخول بلغات متعددة داخل `social-login-demo/` (Google/Facebook) كمثال منفصل.

## كيفاش تشغّل الموقع؟
1. فك الضغط على الملف ZIP.
2. افتح مجلد `Deutsch_Lernen_SEO_V9`.
3. للنشر على Netlify، ارفع محتويات المجلد أو اربط Repository ديالك. إعدادات النشر موجودة فـ `netlify.toml`.
4. راجع `README_DARIJA.md` و`README_SEO_DARIJA.md` قبل النشر.

## مهم بخصوص تسجيل الدخول
الموقع الرئيسي فيه نظام تسجيل الدخول والحسابات باستعمال Supabase. خاصك تكمل الإعدادات فـ `public/config.js` وتضبط متغيرات Netlify حسب دليل المشروع.

المجلد `social-login-demo/` هو نموذج منفصل للتجربة، وأزرار Google/Facebook فيه غير مثال توضيحي؛ ما غاديش تخدم فعلياً حتى تربطها بخدمة OAuth صحيحة. ما تشاركش مفاتيح سرية فالموقع أو GitHub.

## التحقق
شغّل فالمجلد الرئيسي: `npm run check:seo` (يتطلب Python 3).
